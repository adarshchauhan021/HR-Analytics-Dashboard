Power BI HR Analytics Dashboard
Developed an interactive HR Analytics Dashboard in Power BI to analyze employee data, including workforce size, department distribution, salary trends, joining dates, and job status. Used KPIs, charts, slicers, and DAX to deliver clear insights for data-driven HR decision-making.
